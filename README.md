# Getting Started

Follow the instructions below to download, install, and run the application locally.

## 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

Replace `USERNAME` and `REPOSITORY` with the appropriate GitHub details.

## 2. Create a Virtual Environment

Create a Python virtual environment:

```bash
python3 -m venv venv
```

Activate the virtual environment:

**macOS / Linux**
```bash
source venv/bin/activate
```

**Windows**
```bash
venv\Scripts\activate
```

## 3. Install Dependencies

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## 4. Run the Application

Start the application:

```bash
python app.py
```

## 5. Open in Browser

Once the application is running, open your web browser and navigate to:

```text
http://127.0.0.1:5000
```

The application should now be accessible locally.

> **Note:** The URL and port may differ depending on the application's configuration. Check the terminal output for the correct address.

## 6. Stop the Application

Press `Ctrl + C` in the terminal to stop the application.

To deactivate the virtual environment:

```bash
deactivate
```
